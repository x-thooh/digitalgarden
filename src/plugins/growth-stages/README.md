# Growth Stages

Shows each note's maturity as a growth stage: seedling, budding, or evergreen. Set it with growth: seedling in a note's frontmatter.

A plugin for [Digital Garden](https://github.com/oleeskild/digitalgarden) sites.

## Install

Paste this repo's URL into **Settings → Digital Garden → Plugins → Install from GitHub** in Obsidian, or copy this folder into `src/plugins/growth-stages/` in your garden repo.

## Settings

- **Show stage name** — Show the stage name next to the emoji.
